# Sistema visual Menu Bão

## Direção

A linguagem é editorial, humana e operacional. Ela combina a segurança do
petróleo com superfícies inspiradas em papel, tipografia clara e acentos usados
para explicar hierarquia ou estado.

As imagens devem parecer diagramas editoriais bem projetados, não screenshots
genéricos nem anúncios promocionais.

## Paleta

| Papel | Cor |
| --- | --- |
| Fundo principal | `#0d2f2e` |
| Fundo profundo | `#0a2423` |
| Superfície | `#123b3a` |
| Superfície elevada | `#194745` |
| Borda | `#2a5552` |
| Texto principal / papel | `#fff7e8` |
| Texto secundário | `#c8c0b4` |
| Urucum | `#f05a3c` |
| Verde | `#22c55e` |
| Âmbar | `#f59e0b` |
| Azul | `#38bdf8` |

Use petróleo, papel e urucum para identidade. Verde, âmbar e azul devem
comunicar estados, canais ou categorias, não decorar aleatoriamente.

## Tipografia

- Títulos e corpo: Inter.
- Assinatura da marca: Bricolage Grotesque.
- Pesos disponíveis: 400, 600 e 700.
- Títulos de capa: 64 a 82 px.
- Títulos inline: 42 a 58 px.
- Corpo e labels: 22 a 30 px.
- Labels curtas podem usar caixa alta e tracking moderado.

Reduza o tamanho antes de comprimir o espaçamento. Nunca use mais de quatro
linhas no título da capa.

## Composição

- Margem segura mínima: 64 px.
- Grid preferencial: blocos de 8 px.
- Bordas: 1 ou 2 px com contraste discreto.
- Raios: 18 a 32 px para superfícies, menores para pills.
- Prefira campos de cor sólidos e linhas estruturais. Não use glows ou
  gradientes decorativos como assinatura da marca.
- Elementos posicionados depois no JSX aparecem na frente.

## Marca

Não inclua logo, wordmark, categoria, eyebrow ou badge editorial dentro de
capas e imagens inline. A identidade deve vir da paleta, tipografia, composição
e linguagem visual; o contexto de publicação já informa a origem.

O símbolo da marca é reservado para ativos em que ele é o próprio conteúdo,
como favicon e Apple Touch Icon, ou para pedidos explícitos do usuário.

## Acessibilidade

- Contraste mínimo equivalente a WCAG AA para texto essencial.
- Não use verde versus vermelho como única distinção.
- Adicione labels, formas ou posições distintas para estados.
- Evite corpo abaixo de 22 px em uma imagem de 1200 px.
- Alt text deve explicar a informação transmitida.
